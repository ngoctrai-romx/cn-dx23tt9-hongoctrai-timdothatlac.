## Mô tả đề tài

Website cho phép người dùng **đăng tin mất đồ** hoặc **nhặt được đồ**, từ đó kết nối người mất và người nhặt được một cách nhanh chóng, có tổ chức. Hệ thống bao gồm tìm kiếm, phân loại đồ vật theo danh mục, và trang quản trị cho Admin.

## Công nghệ sử dụng

- **Frontend:** Next.js (React)
- **Backend:** Next.js API Routes
- **Database:** MongoDB + Mongoose
- **Auth:** NextAuth.js
- **Styling:** CSS thuần
