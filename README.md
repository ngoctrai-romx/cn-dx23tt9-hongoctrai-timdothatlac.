## Công nghệ

- ASP.NET Web Forms (.NET Framework 4.x)
- C# và ADO.NET
- SQL Server / SQL Server Express
- HTML, CSS và JavaScript

## Cài đặt và chạy

1. Cài Visual Studio 2019/2022 với workload **ASP.NET and web development**.
2. Cài SQL Server Express và SQL Server Management Studio.
3. Chạy `Database/AppleStore.sql` bằng SSMS để tạo CSDL và dữ liệu mẫu.
4. Kiểm tra chuỗi kết nối `AppleStoreConnection` trong `web.config`.
5. Trong Visual Studio, chọn **File -> Open -> Web Site**, mở thư mục mã nguồn rồi chạy bằng `Ctrl+F5`.
