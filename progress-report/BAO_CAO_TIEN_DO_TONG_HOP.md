# Báo cáo tiến độ tổng hợp

## Giai đoạn 1 - Phân tích và thiết kế

- Xác định hai phân hệ khách hàng và quản trị.
- Thiết kế CSDL SQL Server gồm 6 bảng.
- Xây dựng sơ đồ chức năng, ERD và luồng xử lý chính.

## Giai đoạn 2 - Hiện thực

- Hoàn thiện chức năng sản phẩm, tìm kiếm, giỏ hàng, đặt hàng và tài khoản.
- Hoàn thiện quản trị sản phẩm, danh mục, đơn hàng, khách hàng và thống kê.
- Bổ sung dữ liệu mẫu 22 sản phẩm và ảnh minh họa.

## Giai đoạn 3 - Kiểm thử và tài liệu

- Triển khai thử nghiệm trên IIS và SQL Server Express.
- Kiểm tra 17 trường hợp chức năng chính.
- Hoàn thiện báo cáo, slide, video demo, README và script CSDL.

## Trạng thái cuối

- Website chạy được trên IIS với CSDL AppleStore.
- Báo cáo và slide sử dụng ảnh chụp thực tế từ hệ thống đã triển khai.
- Mã nguồn đã loại bỏ `.git`, `bin` và `obj` trong gói nộp.
