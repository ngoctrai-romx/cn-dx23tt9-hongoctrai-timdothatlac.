# Hướng dẫn triển khai

1. Cài IIS với ASP.NET 4.x hoặc mở dự án bằng Visual Studio 2019/2022.
2. Cài SQL Server Express.
3. Chạy `AppleStore.sql` để tạo CSDL `AppleStore`, 6 bảng và dữ liệu mẫu.
4. Sửa `Data Source` trong `web.config` cho đúng instance SQL Server.
5. Trỏ IIS/Visual Studio vào thư mục `scr/AppleStore` và mở `Default.aspx`.
